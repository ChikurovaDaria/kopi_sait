# TONA

Учебная копия сайта TONA. React, TypeScript и CSS; изображения, шрифты и видео находятся в проекте.

## Что загружать на GitHub

Загрузите всё содержимое этой папки, включая скрытый `.gitignore`: `src`, `public`, `docs`, `scripts`, конфигурации, `package.json`, `pnpm-lock.yaml`, README и файл запуска. Папку `node_modules` загружать не нужно.

## GitHub Pages

Готовый сайт находится в `docs`. После загрузки репозитория откройте **Settings → Pages → Deploy from a branch**, выберите ветку **main** и папку **/docs**, затем Save. В интернете сайт появится после завершения публикации GitHub. Сайт опубликован: https://chikurovadaria.github.io/kopi_sait/

Если нужны только файлы готового сайта без исходников, можно загрузить содержимое `docs` в корень отдельного репозитория и выбрать **/(root)**. `index.html` должен находиться прямо в выбранной папке публикации.

## Запуск и разработка

Для просмотра готового сайта нужен Node.js: откройте «Запустить TONA.cmd» и перейдите на http://localhost:4187/. Для остановки нажмите Ctrl+C.

Для редактирования установите зависимости командой `npm install` или `pnpm install`. Команды: `npm run dev`, `npm run check`, `npm run build`. После изменения исходников обновите сборку в `docs` перед загрузкой на GitHub.

`src` — исходный код и стили; `public` — ресурсы для сборки; `docs` — готовая сборка для публикации; `scripts/serve.mjs` — локальный сервер. Ресурсы в `public` и `docs` нужны для разных этапов, поэтому удалять одну из этих папок из полного проекта не следует.

Форма сохраняет заявки только в браузере на устройстве. Отправка писем и сервер приёма заказов не подключены.
